# 数字签名的功能

## 1. 原题
**题干：** 数字签名的功能不包括（ ）。
**选项：**
- [ ] A. 防止发送方和接收方的抵赖行为
- [ ] B. 发送方身份确认
- [x] C. 接收方身份确认
- [ ] D. 保证数据的完整性
**我的答案：** 未作答 / 错误（若答错，例如选了A）
**正确选项：** C

## 2. 知识点
- **核心概念：** **数字签名**是利用发送方的私钥对消息摘要进行加密，以供接收方用发送方公钥验证的技术。
- **核心三功能：**
  1.  **身份认证**：验证消息的来源。
  2.  **数据完整性**：验证消息未被篡改。
  3.  **不可否认性**：防止发送方事后否认其发送行为。
- **关键技术：** 非对称加密、哈希函数。

## 3. 详细解析
1.  **基于原理的判断：**
    - 数字签名的生成和验证只涉及**发送方的私钥和公钥**。
    - 因此，它能证明一切与“发送方”相关的属性，但无法证明与“接收方”相关的任何属性。
2.  **逐项判断：**
    - **B. 发送方身份确认：** ✅ 是核心功能。用发送方公钥成功验证签名，即确认了其身份。
    - **D. 保证数据的完整性：** ✅ 是核心功能。通过比对哈希值实现。
    - **A. 防止发送方和接收方的抵赖行为：** ⚠️ **有争议，但常被认定为功能。** 它能强力防止**发送方**抵赖。但不能直接防止**接收方**抵赖（如抵赖收货）。在考试常见语境下，此选项被接受为数字签名的功能。
    - **C. 接收方身份确认：** ❌ **绝对不是其功能。** 整个流程与接收方的私钥无关，发送方无法通过数字签名确认是谁收到了消息。

## 4. 错误选项分析
- **如果误选A：** 可能是对“不可否认性”的理解不够精确，忽略了其主要是防止发送方抵赖，或者受到了考试常见语境的影响。但在与C选项对比时，C的“错误性”是绝对的。
- **如果误选B或D：** 说明对数字签名的基本原理尚未掌握。

## 5. 记忆技巧与总结
- **一句话总结：** 数字签名是“**自证清白**”，它能向所有人证明“**这是我发的，且内容没改过**”，但它不管“**你是谁**”。
- **判断口诀：** “**签名只管发送方，接收身份它不管**”。
- **公钥私钥使用口诀：** “**私钥签名，公钥验证；公钥加密，私钥解密**”。

## 6. 巩固练习
**练习1：**
为了保证数据传输的安全性，采用数字信封技术。该技术中，对会话密钥使用的加密算法是（）。
**答案：** C. 接收方的公钥
**解析：** 数字信封为保证保密性，使用接收方的公钥加密会话密钥。

**练习2：**
（多选题）下列安全功能中，数字签名技术能够直接提供的有（）。
**答案：** B, C, D
**解析：** 数字签名直接提供完整性(B)、身份认证(C)和不可否认性(D)，但不提供机密性(A)。
