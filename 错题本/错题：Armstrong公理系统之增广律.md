## 原题
> 给定关系模式 R<U,F>;其中 U 为属性集，F 是 U 上的一组函数依赖，那么Armstrong 公理系统的增广律是指（ ）。

- **我的答案**：[此处可填写你的原始选择]
- **正确答案**：D (若 X→Y，为 F 所蕴涵，且 Z包含于U,则 XZ→YZ 为 F 所蕴涵)

## 深度解析

### 核心考点
本题考察 **"Armstrong公理系统三条基本公理的准确记忆与区分"**。

### 逐项分析
- **D（增广律）为什么正确**：
  - 增广律的标准表述是：如果 X → Y 成立，那么在两边同时增加任意属性集 Z 后，XZ → YZ 也成立。
  - 选项D "若 X→Y，为 F 所蕴涵，且 Z包含于U,则 XZ→YZ 为 F 所蕴涵" 与此完全一致。

- **A为什么错误**：
  - 描述的是**合并规则**（Union Rule），这是从公理推导出的推理规则，不是基本公理。

- **B为什么错误**：
  - 描述的是**伪传递规则**（Pseudo-transitivity Rule），也是推导出的推理规则。

- **C为什么错误**：
  - 描述的是**传递律**（Transitivity Rule），这是Armstrong公理系统的第三条公理。

### 知识总结：Armstrong公理系统

**三大基本公理：**
1. **自反律**：若 Y ⊆ X，则 X → Y
2. **增广律**：若 X → Y，则 XZ → YZ  
3. **传递律**：若 X → Y 且 Y → Z，则 X → Z

**重要推理规则（由公理推导）：**
- **合并规则**：若 X → Y 且 X → Z，则 X → YZ
- **分解规则**：若 X → YZ，则 X → Y 且 X → Z
- **伪传递规则**：若 X → Y 且 WY → Z，则 XW → Z

**记忆口诀：**
- **自反**：整体决定部分
- **增广**：两边同时加料
- **传递**：A→B→C ⇒ A→C
