# 性能评价程序的准确度

## 1. 原题
**题干：** 为了测试新系统的性能，用户必须依靠评价程序来评价机器的性能，以下4种评价程序，（ ）评测的准确程度最低。
**选项：**
- [ ] A. 小型基准程序
- [ ] B. 真实程序
- [ ] C. 核心程序
- [x] D. 合成基准程序
**我的答案：** 未作答 / 错误（若答错，例如选了A）
**正确选项：** D

## 2. 知识点
- **核心概念：** 评估计算机系统性能时，使用的基准程序越贴近用户的实际应用，其评估结果就越准确。
- **评价程序类型（按准确度从高到低排序）：**
  1.  **真实程序：** 实际使用的应用程序，最能反映真实性能。
  2.  **核心程序：** 从真实程序中提取的计算密集型核心代码片段，代表性好。
  3.  **小型基准程序：** 小型但完整的程序，测试特定方面，但代表性不足。
  4.  **合成基准程序：** 人为构造的、无实际功能的程序，指令比例基于统计，准确度最低。

## 3. 详细解析
- **D. 合成基准程序：** 准确度最低。因为它是人为合成的，其程序结构、数据访问模式和控制流与真实程序差异很大，无法真实反映系统在处理实际任务时的行为（如缓存命中率、分支预测效率等）。它试图模拟“平均”情况，但往往与任何“具体”情况都不符。
- **其他选项分析：**
  - **B. 真实程序 & C. 核心程序：** 都源于实际应用，准确度高。
  - **A. 小型基准程序：** 虽有局限，但它是一个真实、完整的程序，其行为是自然的，因此准确度高于人为拼凑的合成基准程序。

## 4. 错误选项分析
- **如果误选A：** 可能混淆了“小型基准程序”和“合成基准程序”。虽然两者准确度都不高，但“小型”是真实的，“合成”是虚构的，后者准确度更差。

## 5. 记忆技巧与总结
- **准确度排序口诀：** “**真实核心固然好，小型合成精度少；若问谁是最不准，人造合成跑不了。**”
- **关键区分：**
  - **有真实功能 vs 无真实功能**：这是判断准确度的关键。有真实功能的程序（即使很小）其行为模式是自然的；而无真实功能的合成程序行为是人为的、僵硬的。
- **现代实践：** 像SPEC这样的权威标准，都趋向于使用**真实程序**作为基准。

## 6. 巩固练习
**练习1：**
在计算机系统性能评估中，SPEC（标准性能评估公司）组织发布的CPU基准测试套件主要基于（）。
**答案：** B. 真实程序
**解析：** SPEC的权威性正来自于它使用一系列真实应用程序作为测试负载。

**练习2：**
（判断题）核心程序因为剔除了真实程序中的I/O等无关操作，所以它比真实程序更能准确反映系统的实际性能。
**答案：** B. 错误
**解析：** “实际性能”是综合性能。核心程序忽略了I/O等子系统，无法全面反映整体性能，因此对于“系统实际性能”而言，真实程序更准确。
