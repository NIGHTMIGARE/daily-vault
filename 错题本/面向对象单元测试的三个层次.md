# 

## 原题
面向对象系统的单元测试包括方法层次的测试、类层次的测试和类树层次的测试。在常见的测试技术中， （1） 属于方法层次的测试， （2） 属于类层次的测试。

**问题（1）选项：**
A. 等价类划分测试和多态消息测试
B. 不变式边界测试和递归函数测试
C. 组合功能测试和非模态类测试
D. 不变式边界测试和模态类测试

## 正确答案
**（1） A. 等价类划分测试和多态消息测试**

（尽管A不纯粹，但它是四个选项中最能代表方法层次的）

## 解题分析
### 三个测试层次的核心区别
1.  **方法层次**：
    - **关注点**：**单个方法**的内部逻辑。
    - **技术特点**：主要继承传统过程式程序的测试技术。
    - **正确技术举例**：**等价类划分、边界值分析、基本路径测试、递归函数测试**。
    - **选项分析**：A中的“等价类划分测试”是典型的方法层次技术。

2.  **类层次**：
    - **关注点**：一个**类**的多个方法之间的交互，以及**对象状态**的变化。
    - **技术特点**：关注对象的生命周期和状态。
    - **正确技术举例**：**不变式边界测试、模态类测试、组合功能测试**。
    - **选项分析**：B、C、D中包含的技术大多属于类层次。

3.  **类树层次**：
    - **关注点**：**继承体系**中多个类之间的交互，特别是**多态**行为。
    - **技术特点**：关注动态绑定和继承。
    - **正确技术举例**：**多态消息测试、展平测试**。
    - **选项分析**：A中的“多态消息测试”属于此类。

## 核心概念总结
### 层次与技术对应表
| 测试层次 | 核心测试目标 | 典型测试技术 |
| :--- | :--- | :--- |
| **方法层次** | 方法内部正确性 | 等价类划分、边界值分析、基本路径测试、逻辑覆盖 |
| **类层次** | 对象状态、方法交互 | 不变式边界测试、模态类测试、组合功能测试 |
| **类树层次** | 继承、多态 | 多态消息测试、展平测试 |

## 易错点
- 此题选项设计并非“完美”，需要选择**最符合**层次定义的选项。
- **关键区分**：
  - 测试**一个方法**的内部 -> 方法层次。
  - 测试**一个对象**的状态和多个方法 -> 类层次。
  - 测试**一群有继承关系的类** -> 类树层次。
- “多态消息测试”虽然出现在选项A中，但它本身是类树层次的技术。题目选择A是因为“等价类划分”是更强的方法层次标志。
