# 现有系统分析的正确与错误方法

## 1. 原题
**题干：** 在对于现有系统进行分析时，（ ）方法是错误的。
**选项：**
- [ ] A. 多与用户沟通，了解他们对现有系统的认识和评价
- [ ] B. 了解现有系统的组织结构，输入/输出、资源利用情况和数据处理过程
- [x] C. 理解现有系统“做什么”的基础上，抽取其“怎么做”的本质
- [ ] D. 从对现有系统的物理模型出发，通过研究、分析建立起其较高层次的逻辑模型描述
**我的答案：** 未作答 / 错误（若答错）
**正确选项：** C

## 2. 知识点
- **核心概念：** 系统分析阶段的核心任务是**理解和抽象现有系统的业务逻辑**，为新系统设计做准备。
- **关键模型：**
  - **物理模型：** 描述系统“**怎么做**”，涉及具体的技术、工具、人员、部门等实现细节。是分析的**起点**。
  - **逻辑模型：** 描述系统“**做什么**”，是业务的本质，剥离了所有物理实现细节。是分析的**目标和成果**。
- **标准流程：** **物理模型 -> (分析抽象) -> 逻辑模型**

## 3. 详细解析
1.  **正确方法分析：**
    - **A 和 B：** 是获取现有系统**物理模型**信息的正确手段，是分析的基础。
    - **D：** 精准地描述了系统分析的标准过程和目标：从具体的“物理模型”抽象出本质的“逻辑模型”。
2.  **错误方法分析（选项C）：**
    - **方向性错误：** 系统分析的正确方向是从“怎么做”（物理）中提炼出“做什么”（逻辑）。而选项C提出从“做什么”中抽取“怎么做”，这完全本末倒置。
    - **逻辑混乱：** “怎么做”是具体的实现方式，是表象，不是需要被“抽取”的“本质”。我们真正要抽取的“本质”是“做什么”。

## 4. 错误选项分析
- **如果误选其他项：** 可能对“逻辑模型”和“物理模型”的概念以及它们在系统分析过程中的关系和转换方向理解不够清晰。需要牢记分析的目的是“**去物理化，得逻辑化**”。
