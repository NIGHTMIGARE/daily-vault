## 原题
在黑盒测试方法中，（ ）方法最适合描述在多个逻辑条件取值组合所构成的不同情况下，分别要执行哪些不同的动作。

**选项：**
A. 等价类
B. 边界值
C. 判定表
D. 因果图

## 正确答案
**C. 判定表**

## 解题分析
- **题干关键词**：“多个逻辑条件”、“取值组合”、“执行哪些不同的动作”。这描述了一个典型的**基于逻辑条件的业务规则决策**场景。
- **判定表** 是一种以表格形式表达**条件组合**与**对应动作**之间逻辑关系的工具。它系统地列出了所有可能的条件组合（规则），并明确规定了每种组合下应执行的动作，因此**最适合**题目描述的场景。
- **其他选项辨析**：
  - **A. 等价类**：关注单个输入数据的分类，不擅长处理多个条件间的组合逻辑。
  - **B. 边界值**：关注输入范围的边界，是等价类的补充，与条件组合无关。
  - **D. 因果图**：用于分析因（输入）和果（输出/动作）之间的逻辑关系，并能处理约束。它是一个**分析过程**，其分析结果通常需要**转换为判定表**来生成测试用例。因此，对于“描述”这一直接需求，判定表比因果图更合适。

## 核心概念总结
### 主要黑盒测试方法对比
| 方法 | 核心用途 | 形象比喻 |
| :--- | :--- | :--- |
| **等价类划分** | 测试**数据范围**的代表性样本 | “抽样检查” |
| **边界值分析** | 测试数据范围的**边界区域** | “检查围墙的接缝处” |
| **判定表** | 测试**业务规则**（`if...then...`）的所有组合 | “决策清单”或“自动化规则表” |
| **因果图** | 分析**输入与输出**之间的复杂逻辑关系和约束 | “逻辑关系图” |

### 判定表的构成
一个判定表通常包含四部分：
1.  **条件桩**：列出所有可能的条件。
2.  **动作桩**：列出所有可能采取的动作。
3.  **条件项**：列出条件桩中条件的各种取值组合。
4.  **动作项**：列出在条件项各组取值情况下应采取的动作。

## 易错点
- 混淆**判定表**和**因果图**。记住：**因果图是分析工具（过程），判定表是表现工具（结果）**。当题目直接问“描述”条件组合与动作时，优先选判定表。
- 看到题干中出现 **“如果...并且...那么...”** 这类表示业务规则的描述时，应立刻联想到判定表。
