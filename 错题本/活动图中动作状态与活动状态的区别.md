# UML活动图 - 动作状态 vs. 活动状态

## 1. 原题
**题干：** 在UML活动图中，（）是原子的，不能被分解、没有内部转移、没有内部活动，它的工作所占用的时间可以忽略。
**选项：**
- [ ] A. 初始状态
- [ ] B. 原子状态
- [ ] C. 活动状态
- [x] D. 动作状态
**我的答案：** 未作答 / 错误（若答错，例如选了B或C）
**正确选项：** D

## 2. 知识点
- **核心概念：** **UML活动图的基本节点类型**。
- **动作状态：**
  - **语义：** 代表一个**原子的、不可中断**的执行步骤。
  - **特性：** **不可分解**、没有内部转移、执行时间可忽略。
  - **类比：** 程序中的一个简单赋值语句 `i = 0;`。
- **活动状态：**
  - **语义：** 代表一个**可分解、非原子**的工作单元。
  - **特性：** **可以被分解**为一系列子活动或动作，内部可以有流，执行持续一段时间。
  - **类比：** 程序中的一个函数调用 `processOrder();`，这个函数内部包含多条语句。
- **关键区别：** **是否可分解** 是区分二者的根本标准。

## 3. 详细解析
1.  **题干关键词分析：** “原子的”、“不能被分解”、“没有内部转移”、“时间可以忽略”。这四个描述都精确地指向了**动作状态**的定义。
2.  **逐项排除：**
    - **A. 初始状态：** 是起点伪状态，非工作单元。
    - **B. 原子状态：** 非UML标准术语，是干扰项。
    - **C. 活动状态：** 与题目描述完全相反，它是可分解、有内部活动的。
    - **D. 动作状态：** 完全符合所有描述。

## 4. 错误选项分析
- **B. 原子状态：** 利用了“原子”一词进行干扰，但UML规范中无此元素，选它说明对官方术语不熟悉。
- **C. 活动状态：** 这是最常见的错误选择，混淆了“动作”和“活动”的根本区别。选它说明没有抓住“可分解性”这一关键判别标准。

## 5. 图形与记忆技巧
- **图形表示：** 两者都是**圆角矩形**。不能靠图形简单区分。
- **记忆口诀：** “**动作原子瞬时完，活动复杂可展开**”。
- **考试技巧：** 看到“原子”、“不可分解”、“瞬时”等词，直接锁定“**动作状态**”。

## 6. 巩固练习
**练习1：**
在UML活动图中，哪个元素用于表示一个可以进一步分解为若干子步骤的非原子性工作单元？
**答案：** B. 活动状态
**解析：** “可分解”和“非原子性”是活动状态的标志性特征。

**练习2：**
（判断题）在UML 2.x中，活动图中的动作状态和活动状态在图形表示上有明显的、不可混淆的区别。
**答案：** B. 错误
**解析：** 两者图形相同，均为圆角矩形，区别在于语义。
