## 题目
> 在面向对象设计的原则中，（ ）原则允许一个类可以在不改变原有代码的情况下来变更它的行为。  
> A. 开闭  
> B. 里氏替换  
> C. 最少知识  
> D. 依赖倒置

## 答案
**A. 开闭原则**

## 各原则解析

### 1. 开闭原则 (OCP)
- **核心**：对扩展开放，对修改关闭
- **实现方式**：通过抽象（接口/抽象类）和多态，允许通过继承或组合扩展功能
- **例子**：
  ```java
  interface Shape { double area(); }
  class Circle implements Shape { ... }
  class Rectangle implements Shape { ... }
  // 新增 Triangle 类不影响原有代码
