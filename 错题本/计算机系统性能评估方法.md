# 计算机系统性能评估方法

## 1. 时钟频率法
- **原理：** 使用CPU主时钟频率评估。
- **公式/单位：** Hz (MHz, GHz)
- **特点：** 最粗略，已基本淘汰。

## 2. 等效指令速度法 (吉布森混合法)
- **原理：** **考虑各类指令的使用比例**，计算加权平均速度。
- **公式：** \( T = \sum_{i=1}^{n} (F_i \times T_i) \)
  - \( T \)：平均指令时间
  - \( F_i \)：第i类指令的使用频率
  - \( T_i \)：第i类指令的执行时间
- **特点：** 比主频法准确，但指令混合比例难以精确统计。

## 3. 综合理论性能法
- **原理：** 计算CPU处理定点、浮点数据的**理论峰值性能**。
- **公式/单位：** MFLOPS, MIPS
- **特点：** 反映理论极限，与实际性能有差距。

## 4. 基准程序法
- **原理：** 运行一组标准的、有代表性的程序来**实测系统性能**。
- **常见基准程序：** SPEC CPU, TPC-C, Linpack
- **特点：**
  - **最准确、最可靠**的方法。
  - **能综合反映**CPU、Cache、内存、**I/O结构、操作系统、编译程序**等对性能的影响。
