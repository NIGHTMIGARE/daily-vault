## 原题
> 关系模式R(U,F)，U={A,B,C}，F={A→B,B→C}。分解为ρ={R1(A,B), R2(A,C)}，分解ρ（ ）。

- **我的答案**：[此处可填写你的原始选择]
- **正确答案**：D (无损连接但不保持函数依赖)

## 深度解析

### 核心考点
本题考察 **"关系模式分解的无损连接性和函数依赖保持性的判断"**。

### 解题步骤
**1. 无损连接性判断**
- 使用**chase test**（追逐法/矩阵法）：
  - 初始表：R1: (a,b,c₁), R2: (a,b₂,c)
  - 应用A→B：使B列相同 ⇒ R2的B改为b
  - 应用B→C：使C列相同 ⇒ R1的C改为c
  - **得到一行(a,b,c) ⇒ 无损连接**

**2. 函数依赖保持性判断**
- 原F = {A→B, B→C}
- R1的F1 = {A→B} （保持A→B）
- R2的F2 = {A→C} （**B→C丢失**！）
- F1∪F2 = {A→B, A→C} **无法推导出 B→C**
- **⇒ 不保持函数依赖**

### 知识总结：分解性质判定

**无损连接性判定：**
- **方法**：Chase test/矩阵法
- **关键**：能否通过函数依赖使某行变为全a
- **充分条件**：R1∩R2 → R1-R2 或 R1∩R2 → R2-R1

**函数依赖保持性判定：**
- **方法**：检查每个原FD是否被 (F1∪F2)⁺ 逻辑蕴含
- **关键**：不能有任何原FD丢失

**理想分解**：同时满足**无损连接** + **函数依赖保持**

> **Q2**: S(学号,课程,成绩,教师,职称), F={(学号,课程)→成绩,课程→教师,教师→职称}, 分解为S1(学号,课程,成绩),S2(课程,教师,职称)，该分解？
> **A. 无损+保持 B. 无损不保持 C. 有损保持 D. 有损不保持**
> **答案：A**
> ## 快速判定技巧

**无损连接快速判定法：**
如果满足 **R1∩R2 → R1-R2** 或 **R1∩R2 → R2-R1**，则分解无损。

**应用到本题：**
- R1∩R2 = {A}
- R1-R2 = {B}, R2-R1 = {C}
- A→B 在F中成立 ⇒ **立即判定为无损**

**优势：**
- 无需构建复杂表格
- 大多数考题都适用
- 10秒内得出答案
